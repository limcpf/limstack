## 협업 기준

- **PR** — 독립 변경 하나, 추가·삭제 100줄 안팎, 최대 200줄. [생성 파일·설명 주석 집계](개발-협업.md#pr-크기)
- **작업 공간** — 새 PR마다 전용 브랜치·Git worktree. 후속 수정은 기존 폴더 사용. 독립 작업은 병렬 진행.
- **리뷰** — 한국어 커밋·PR, `ponytail:ponytail`로 코드 필요성 검토, PR마다 학습 질문이나 실습 하나.
- **학습 기록** — `~/documents/markdowns/knowledge/`. 첫 사례는 `PR에서 설명 주석을 변경 줄 수와 구분하기.md`.
