# limstack 설계 문서

limstack은 Markdown으로 작성한 기술 문서를 주제별 stack으로 읽는 개인 정적 사이트야.

이전 작업을 이어갈 때는 [세션 인수인계](세션-인수인계.md)에서 현재 단계와 합의한 결정을 먼저 확인해.

## 읽는 순서

1차 구현을 시작할 때는 승인된 1~3번을 순서대로 읽어. 4번은 로컬 구현을 마친 뒤에 보면 돼.

1. [로컬 구현](로컬-구현.md) — 기술 구성, 구현 범위, 완료 조건
2. [문서 작성과 공개](문서-작성과-공개.md) — 원본 위치, URL, 초안과 경고, 단일 문서 빌드
3. [읽기 화면](읽기-화면.md) — 홈과 목록, 문서 조판, Markdown, 접근성
4. [검토와 배포](검토와-배포.md) — 2차 설계. 빌더 릴리스, Telegram 캡처와 GitHub 승인 배포

[홈과 문서 상세 화면 스케치](화면-스케치.html)에서 접힌 목차와 본문 배치를 볼 수 있어.

설계 문서는 이 저장소의 `docs/`에서 관리해. 모바일에서는 `~/documents/markdowns/projects/limstack/README.md`의 링크로 GitHub에 있는 최신본을 열어.
