# limstack 설계 문서

limstack은 Markdown으로 작성한 기술 문서를 주제별 stack으로 읽는 개인 정적 사이트야.

| 문서 | 검토할 내용 | 상태 |
| --- | --- | --- |
| [로컬 구현](로컬-구현.md) | 기술 구성, 구현 범위, 완료 조건 | 1차 승인 |
| [문서 작성과 공개](문서-작성과-공개.md) | 원본 위치, URL, 초안과 경고, 단일 문서 빌드 | 1차 승인 |
| [읽기 화면](읽기-화면.md) | 홈과 목록, 문서 조판, Markdown, 접근성 | 1차 승인 |
| [검토와 배포](검토와-배포.md) | 빌더 릴리스, Telegram 캡처와 GitHub 승인 배포 | 2차 설계 |

[홈과 문서 상세 화면 스케치](화면-스케치.html)에서 접힌 목차와 본문 배치를 볼 수 있어.

문서 원본은 프로젝트의 `docs/`에서 편집해. 개인 Syncthing 폴더의 `markdowns/projects/limstack/docs/`는 모바일 열람용 사본이야.
