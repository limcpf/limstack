# 로컬 구현

Ubuntu에서 Astro 기반의 개인 기술 문서 사이트 **limstack**을 구현해줘. 공부한 내용을 주제별 stack에 쌓고, 독자가 링크를 열어 바로 읽을 수 있는 사이트야. 로컬에서 초안을 확인하고, `npm run build`로 공개 글만 담은 `dist/`를 만든 뒤 `npm run preview`에서 읽을 수 있으면 1차 완료야.

## 기술과 범위

현재 디렉터리와 프로젝트 지침을 확인하고 기존 사용자 작업을 보존해줘. Astro, TypeScript, Content Collections, 일반 Markdown, Astro 컴포넌트와 기본 CSS를 사용해 정적으로 생성해줘. npm을 기본으로 쓰고, 기존 설정이 있으면 존중해줘. 설치한 Astro 버전의 공식 API를 사용해줘.

1차 범위는 문서 작성, 로컬 검토, 정적 빌드까지야. GitHub Actions, Telegram, Cloudflare 연동은 로컬 사이트 완성 후 2차에서 진행해.

[작성·공개 규칙](문서-작성과-공개.md)과 [읽기 화면](읽기-화면.md)을 함께 적용해.

## 완료 조건

1. 개발 서버에서 홈, stack 목록, 문서 상세와 초안을 확인해줘.
2. `build:doc`으로 `Example` 한 편을 빌드하고, `npm run build`로 `dist/`를 만들어줘.
3. `npm run preview`에서 문서, 이미지, 수식, Mermaid, 404를 확인해줘. 초안 페이지와 초안 전용 이미지는 공개 결과에서 빠져야 해.
4. 정상 공개 글과 YAML이 깨진 파일을 함께 빌드해, 정상 글이 생성되고 깨진 파일의 경고가 표시되는지 확인해줘.
5. 모바일 너비, 인쇄 미리보기, 키보드 탐색, JavaScript를 끈 상태를 확인해줘.
6. 실행 가능한 소스와 `dist/`, 짧은 README를 제공해줘. README에는 실행·빌드·미리보기 명령과 글·이미지 작성 예시를 담아줘. Markdown 수집, 파일 경로에서 URL이 정해지는 방식, HTML 생성, 빌드와 브라우저의 역할을 Java/Spring 개발자가 이해하기 쉽게 설명해줘. 마지막에 주요 파일의 역할, 실제 검증 결과, 확인하지 못한 항목을 알려줘.
